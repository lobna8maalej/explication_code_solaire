📅 Appointments Dashboard

DashboardAppointments.jsx is the React component used by the administration to view appointments booked by customers. It retrieves appointments from the backend using Axios, stores them in local state with useState, and then displays them as cards.

The component allows the administrator to view the main information associated with each appointment, including the customer's name, email address, phone number, requested date, address, message, and appointment status.
