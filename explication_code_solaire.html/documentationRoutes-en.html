# 17 — Backend API Routes

The files located in the routes folder define the different URLs of the Solar Energy Backend API.

Each route receives an HTTP request from the React frontend and forwards it to the corresponding controller.

General route structure 

const express = require("express"); 
 
const router = express.Router(); 
 
router.get("/", controller); 
 
module.exports = router;
  • express imports the Express framework.
  • express.Router() allows you to create an independent router.
  • The GET, POST, PUT and DELETE methods define the API operations.
  • The controller contains the logic executed when the route is called.
  • module.exports allows the router to be used in app.js.

# 18 — Appointment Routes

The file appointmentRoutes.js is used to manage customer appointments. 

const express = require("express"); 
 
const router = express.Router(); 
 
const { 
    createAppointment, 
    getAppointments, 
    getAppointmentById, 
    updateAppointment, 
    deleteAppointment,

Create an appointment

    "/", 
    createAppointment 
);

This route uses the POST method to create a new appointment.

Get all appointments 

router.get( 
    "/", 
    getAppointments 
);

This route returns the list of appointments stored in MongoDB.

Get an appointment by ID 

router.get(
