Environment Variable Configuration

The .env file contains the environment variables required for the backend of the Solar Energy platform to operate. These variables are used to configure the server, database, authentication, payments, image storage, and email delivery.

Important: API keys, secrets, passwords, and credentials must never be published in documentation, on GitHub, or in publicly accessible source code.

Example of a .env file

 
PORT=3000 
 
MONGO_URI=mongodb://127.0.0.1:27017/solar_db 
 
JWT_SECRET=your_secret_key 
 
STRIPE_SECRET_KEY=your_stripe_secret_key 
 
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name 
CLOUDINARY_API_KEY=your_cloudinary_api_key 
CLOUDINARY_API_SECRET=your_cloudinary_api_secret 
 
EMAIL_USER=your_email@example.com 
EMAIL_PASS=your_email_app_password

Explanation of the variables

PORT

PORT defines the port used by the Node.js/Express server. In this example, the backend runs on port 3000.
