# 17 — Rotas da API Backend

Os arquivos presentes na pasta routes definem as diferentes URLs da API Backend do Solar Energy.

Cada rota recebe uma requisição HTTP proveniente do frontend React e a encaminha para o controller correspondente.

Estrutura geral de uma rota 

const express = require("express"); 
 
const router = express.Router(); 
 
router.get("/", controller); 
 
module.exports = router;
  • express importa o framework Express.
  • express.Router() permite criar um router independente.
  • Os métodos GET, POST, PUT e DELETE definem as operações da API.
  • O controller contém a lógica executada quando a rota é chamada.
  • module.exports permite utilizar o router no app.js.

# 18 — Rotas de agendamentos

O arquivo appointmentRoutes.js é utilizado para gerenciar os agendamentos dos clientes. 

const express = require("express"); 
 
const router = express.Router(); 
 
const { 
    createAppointment, 
    getAppointments, 
    getAppointmentById, 
    updateAppointment, 
    deleteAppointment, 
} = require("../controllers/appointmentController");

As funções do controller são importadas para serem utilizadas pelas diferentes rotas.

Criar um agendamento 

router.post( 
    "/", 
    createAppointment 
);

Esta rota utiliza o método POST para criar um novo agendamento.

Obter todos os agendamentos 

router.get( 
    "/", 
    getAppointments 
);

Esta rota retorna a lista de agendamentos armazenados no MongoDB.

Obter um agendamento por ID 

router.get( 
    "/:id", 
    getAppointmentById 
);

:id representa o identificador do agendamento presente na URL.

Atualizar um agendamento 

router.put( 
    "/:id", 
    updateAppointment 
);

Esta rota permite atualizar um agendamento existente.

Excluir um agendamento 

router.delete( 
    "/:id", 
    deleteAppointment 
);

Esta rota exclui o agendamento correspondente ao identificador fornecido.

URL principal: /api/appointments

As operações disponíveis são:

POST → criar
GET → obter
PUT → atualizar
DELETE → excluir

# 19 — Rotas de autenticação e usuários

O arquivo authRoutes.js é utilizado para gerenciar o cadastro, o login e as operações relacionadas aos usuários. 

const { 
    register, 
    login, 
    updateUser, 
    changePassword, 
    getUsers, 
    deleteUser 
} = require("../controllers/authController");

As funções do controller de autenticação são importadas de authController.js.

Criar uma conta 

router.post( 
    "/register", 
    register 
);

Esta rota permite que um novo usuário crie uma conta.

Login 

router.post( 
    "/login", 
    login 
);

Esta rota permite que o usuário faça login. O controller verifica as credenciais de acesso e pode gerar um token JWT.

Obter usuários 

router.get( 
    "/users", 
    getUsers 
);

Esta rota obtém a lista de usuários.

Atualizar um usuário 

router.put( 
    "/:id", 
    updateUser 
);

Esta rota permite atualizar as informações de um usuário identificado pelo seu ID.

Alterar a senha 

router.put( 
    "/:id/password", 
    changePassword 
);

Esta rota permite alterar a senha de um usuário.

Excluir um usuário 

router.delete( 
    "/:id", 
    deleteUser 
);

Esta rota exclui o usuário correspondente ao ID.

Exemplos de URL:

/api/users/register
/api/users/login
/api/users/users
/api/users/:id
/api/users/:id/password
