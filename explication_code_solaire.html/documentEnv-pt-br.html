Configuração das variáveis de ambiente

O arquivo .env contém as variáveis de ambiente necessárias para o funcionamento do backend da plataforma Solar Energy. Essas variáveis permitem configurar o servidor, o banco de dados, a autenticação, os pagamentos, o armazenamento de imagens e o envio de e-mails.

Importante: chaves de API, secrets, senhas e credenciais nunca devem ser publicadas na documentação, no GitHub ou no código fonte acessível publicamente.

Exemplo de arquivo .env

 
PORT=3000 
 
MONGO_URI=mongodb://127.0.0.1:27017/solar_db 
 
JWT_SECRET=your_secret_key 
 
STRIPE_SECRET_KEY=your_stripe_secret_key 
 
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name 
CLOUDINARY_API_KEY=your_cloudinary_api_key 
CLOUDINARY_API_SECRET=your_cloudinary_api_secret 
 
EMAIL_USER=your_email@example.com 
EMAIL_PASS=your_email_app_password

Explicação das variáveis

PORT

PORT define a porta utilizada pelo servidor Node.js/Express. Neste exemplo, o backend funciona na porta 3000.

MONGO_URI

MONGO_URI contém a URL de conexão com o MongoDB. O banco de dados utilizado pela plataforma é chamado de solar_db neste exemplo.

JWT_SECRET

JWT_SECRET é uma chave secreta utilizada para gerar e verificar JSON Web Tokens (JWT). Esses tokens permitem principalmente proteger a autenticação e o acesso às funcionalidades protegidas.

STRIPE_SECRET_KEY

STRIPE_SECRET_KEY corresponde à chave secreta utilizada para se comunicar com a API da Stripe a partir do backend. Ela permite principalmente criar e gerenciar operações de pagamento.

A chave da Stripe deve permanecer estritamente confidencial e nunca deve ser colocada no frontend ou publicada em um repositório do GitHub. Durante a implantação para um cliente, essa variável deve ser configurada com a chave da Stripe da própria conta do cliente.

CLOUDINARY_CLOUD_NAME

CLOUDINARY_CLOUD_NAME identifica a conta da Cloudinary utilizada para armazenar e gerenciar as imagens da plataforma.

CLOUDINARY_API_KEY

CLOUDINARY_API_KEY corresponde à chave de API utilizada pelo backend para se comunicar com a Cloudinary.

CLOUDINARY_API_SECRET

CLOUDINARY_API_SECRET é o secret associado à conta da Cloudinary. Ele deve permanecer confidencial.

EMAIL_USER

EMAIL_USER contém o endereço de e-mail utilizado pelo backend para enviar e-mails, como notificações ou confirmações.

EMAIL_PASS

EMAIL_PASS corresponde à senha ou senha de aplicativo utilizada para autenticar o serviço de envio de e-mails. Ela nunca deve ser exposta publicamente.

Segurança

O arquivo .env deve ser adicionado ao arquivo .gitignore para evitar que seja enviado acidentalmente para o GitHub. 

 
.env 
node_modules/

Quando um projeto é implantado, as variáveis de ambiente devem ser configuradas diretamente no ambiente seguro do servidor ou da plataforma de hospedagem.
