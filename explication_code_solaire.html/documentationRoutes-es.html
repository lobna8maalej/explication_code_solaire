# 17 — Rutas de la API Backend

Los archivos ubicados en la carpeta routes definen las diferentes URL de la API Backend de Solar Energy.

Cada ruta recibe una solicitud HTTP procedente del frontend React y la envía al controller correspondiente.

Estructura general de una ruta 

const express = require("express"); 
 
const router = express.Router(); 
 
router.get("/", controller); 
 
module.exports = router;
  • express importa el framework Express.
  • express.Router() permite crear un router independiente.
  • Los métodos GET, POST, PUT y DELETE definen las operaciones de la API.
  • El controller contiene la lógica que se ejecuta cuando se llama a la ruta.
  • module.exports permite utilizar el router en app.js.

# 18 — Rutas de citas

El archivo appointmentRoutes.js se utiliza para gestionar las citas de los clientes. 

const express = require("express"); 
 
const router = express.Router(); 
 
const { 
    createAppointment, 
    getAppointments, 
    getAppointmentById, 
    updateAppointment, 
    deleteAppointment, 
} = require("../controllers/appointmentController");

Las funciones del controller se importan para ser utilizadas por las diferentes rutas.

Crear una cita 

router.post( 
    "/", 
    createAppointment 
);

Esta ruta utiliza el método POST para crear una nueva cita.

Obtener todas las citas 

router.get( 
    "/", 
    getAppointments 
);

Esta ruta devuelve la lista de citas almacenadas en MongoDB.

Obtener una cita por ID 

router.get( 
    "/:id", 
    getAppointmentById 
);

:id representa el identificador de la cita presente en la URL.

Modificar una cita 

router.put( 
    "/:id", 
    updateAppointment 
);

Esta ruta permite modificar una cita existente.

Eliminar una cita 

router.delete( 
    "/:id", 
    deleteAppointment 
);

Esta ruta elimina la cita correspondiente al identificador proporcionado.

URL principal: /api/appointments

Las operaciones disponibles son:

POST → crear
GET → obtener
PUT → modificar
DELETE → eliminar
