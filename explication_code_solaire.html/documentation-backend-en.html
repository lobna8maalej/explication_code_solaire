# 1 — General Backend Architecture

The backend is the server-side part of the Solar Energy application.

It allows the React frontend to communicate with the MongoDB database through a REST API developed with Node.js and Express.

Technologies used

  • Node.js: JavaScript runtime environment used on the server side.
  • Express: framework used to create the REST API.
  • MongoDB: NoSQL database.
  • Mongoose: library used to interact with MongoDB.
  • JWT: system used for authentication.
  • bcryptjs: library used to secure passwords.
  • Multer: middleware used to handle files.
Architecture:

React Frontend → Axios → Express API → Controllers → Mongoose Models → MongoDB

# 3 — JWT Authentication Middleware

The verifyToken middleware checks whether the user has a valid JWT token. 

const jwt = 
    require("jsonwebtoken"); 
 
const verifyToken = 
    (req, res, next) => { 
 
    try { 
 
        console.log( 
            "Authorization :", 
            req.headers.authorization 
        ); 
 
        const token = 
            req.headers.authorization 
                ?.split(" ")[1]; 
 
        if (!token) { 
 
            return res.status(401).json({ 
 
                success: false, 
 
                message: 
                    "Accès refusé, token manquant", 
 
            }); 
 
        } 
 
        const decoded = 
            jwt.verify( 
                token, 
                process.env.JWT_SECRET 
            ); 
 
        req.user = decoded; 
 
        next(); 
 
    } catch (error) { 
 
        return res.status(401).json({ 
 
            success: false, 
 
            message: 
                "Token invalide", 
 
        }); 
 
    } 
 
}; 
 
module.exports = { 
    verifyToken 
};

How it works

  1. The frontend sends the token in the Authorization header.
  2. The middleware retrieves the token.
  3. JWT verifies the token using JWT_SECRET.
  4. The decoded information is stored in req.user.
  5. next() allows access to the route.
Result:

Protected routes can verify the user's identity using req.user.

# 4 — File Management with Multer 

const multer = 
    require("multer"); 
 
const storage = 
    multer.memoryStorage(); 
 
const upload = 
    multer({ 
 
        storage, 
 
        limits: { 
 
            fileSize: 
                5 * 1024 * 1024, 
 
        }, 
 
    }); 
 
module.exports = upload;

Multer allows the application to receive files sent from the frontend.

memoryStorage() temporarily stores the file in memory.

The maximum allowed file size is 5 MB.
