# 1 — Arquitetura geral do Backend

O backend constitui a parte do servidor da aplicação Solar Energy.

Ele permite que o frontend React se comunique com o banco de dados MongoDB por meio de uma API REST desenvolvida com Node.js e Express.

Tecnologias utilizadas

  • Node.js: ambiente de execução JavaScript no lado do servidor.
  • Express: framework utilizado para criar a API REST.
  • MongoDB: banco de dados NoSQL.
  • Mongoose: biblioteca utilizada para manipular o MongoDB.
  • JWT: sistema utilizado para autenticação.
  • bcryptjs: biblioteca utilizada para proteger as senhas.
  • Multer: middleware utilizado para gerenciar arquivos.
Arquitetura:

React Frontend → Axios → Express API → Controllers → Models Mongoose → MongoDB

    }); 
 
});

Este middleware permite centralizar o gerenciamento dos erros do servidor.

# 3 — Middleware de autenticação JWT

O middleware verifyToken permite verificar se o usuário possui um token JWT válido. 

const jwt = 
    require("jsonwebtoken"); 
 
const verifyToken = 
    (req, res, next) => { 
 
    try { 
 
        console.log( 
            "Authorization :", 
            req.headers.authorization 
        ); 
 
        const token = 
            req.headers.authorization 
                ?.split(" ")[1]; 
 
        if (!token) { 
 
            return res.status(401).json({ 
 
                success: false, 
 
                message: 
                    "Accès refusé, token manquant", 
 
            }); 
 
        } 
 
        const decoded = 
            jwt.verify( 
                token, 
                process.env.JWT_SECRET 
            ); 
 
        req.user = decoded; 
 
        next(); 
 
    } catch (error) { 
 
        return res.status(401).json({ 
 
            success: false, 
 
            message: 
                "Token invalide", 
 
        }); 
 
    } 
 
};

    verifyToken 
};

# 16 — Conclusão

O backend Solar Energy está organizado de acordo com uma arquitetura modular.

Cada funcionalidade possui seu próprio modelo, seu controlador e suas rotas.

  • Os Models definem a estrutura dos dados do MongoDB.
  • Os Controllers contêm a lógica de negócio.
  • As Routes definem os endpoints da API.
  • Os Middleware controlam determinadas solicitações, principalmente a autenticação.
  • O JWT protege o acesso às funcionalidades protegidas.
  • O bcrypt protege as senhas.
  • MongoDB + Mongoose garantem o gerenciamento dos dados.
  • O Stripe permite gerenciar os pagamentos.
  • Os e-mails permitem confirmar as ações realizadas pelos clientes.
Arquitetura final:

Frontend React → Axios → API Express → Routes → Controllers → Mongoose → MongoDB
