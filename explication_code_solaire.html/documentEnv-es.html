Configuración de las variables de entorno

El archivo .env contiene las variables de entorno necesarias para el funcionamiento del backend de la plataforma Solar Energy. Estas variables permiten configurar el servidor, la base de datos, la autenticación, los pagos, el almacenamiento de imágenes y el envío de correos electrónicos.

Importante: las claves API, secretos, contraseñas y credenciales nunca deben publicarse en la documentación, en GitHub ni en el código fuente accesible públicamente.

Ejemplo de archivo .env

 
PORT=3000 
 
MONGO_URI=mongodb://127.0.0.1:27017/solar_db 
 
JWT_SECRET=your_secret_key 
 
STRIPE_SECRET_KEY=your_stripe_secret_key 
 
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name 
CLOUDINARY_API_KEY=your_cloudinary_api_key 
CLOUDINARY_API_SECRET=your_cloudinary_api_secret 
 
EMAIL_USER=your_email@example.com 
EMAIL_PASS=your_email_app_password

Explicación de las variables

PORT

PORT define el puerto utilizado por el servidor Node.js/Express. En este ejemplo, el backend funciona en el puerto 3000.

MONGO_URI

MONGO_URI contiene la URL de conexión a MongoDB. La base de datos utilizada por la plataforma se llama solar_db en este ejemplo.

JWT_SECRET

JWT_SECRET es una clave secreta utilizada para generar y verificar los JSON Web Tokens (JWT). Estos tokens permiten principalmente proteger la autenticación y el acceso a las funcionalidades protegidas.

STRIPE_SECRET_KEY

STRIPE_SECRET_KEY corresponde a la clave secreta utilizada para comunicarse con la API de Stripe desde el backend. Permite principalmente crear y gestionar las operaciones de pago.

La clave de Stripe debe mantenerse estrictamente confidencial y nunca debe colocarse en el frontend ni publicarse en un repositorio de GitHub. Durante el despliegue para un cliente, esta variable debe configurarse con la clave de Stripe de la propia cuenta del cliente.

CLOUDINARY_CLOUD_NAME

CLOUDINARY_CLOUD_NAME identifica la cuenta de Cloudinary utilizada para almacenar y gestionar las imágenes de la plataforma.

CLOUDINARY_API_KEY

CLOUDINARY_API_KEY corresponde a la clave API utilizada por el backend para comunicarse con Cloudinary.

CLOUDINARY_API_SECRET

CLOUDINARY_API_SECRET es el secreto asociado a la cuenta de Cloudinary. Debe mantenerse confidencial.

EMAIL_USER

EMAIL_USER contiene la dirección de correo electrónico utilizada por el backend para enviar correos electrónicos, por ejemplo, notificaciones o confirmaciones.

EMAIL_PASS

EMAIL_PASS corresponde a la contraseña o contraseña de aplicación utilizada para autenticar el servicio de envío de correos electrónicos. Nunca debe exponerse públicamente.

Seguridad

El archivo .env debe añadirse al archivo .gitignore para evitar que se envíe accidentalmente a GitHub. 

 
.env 
node_modules/

Cuando se despliega un proyecto, las variables de entorno deben configurarse directamente en el entorno seguro del servidor o de la plataforma de alojamiento.
