📅 Panel de citas

DashboardAppointments.jsx es el componente React utilizado por la administración para consultar las citas reservadas por los clientes. Recupera las citas desde el backend mediante Axios, las almacena en el estado local con useState y luego las muestra en forma de tarjetas.

El componente permite al administrador consultar la información principal asociada a cada cita, incluyendo el nombre del cliente, su dirección de correo electrónico, número de teléfono, fecha solicitada, dirección, mensaje y estado de la cita.

Gestión del estado

El componente utiliza useState para crear dos estados. La variable appointments contiene la lista de citas recuperadas desde la API y se inicializa con un array vacío. La variable loading indica si los datos todavía se están cargando.

Estos estados permiten que React actualice automáticamente la interfaz cuando se recuperan las citas o cuando ocurre un error durante la comunicación con el backend.

Recuperación de citas

El hook useEffect se ejecuta automáticamente cuando se carga el componente. Llama a la función fetchAppointments(), que envía una solicitud HTTP GET al endpoint /api/appointments.

Esta solicitud permite recuperar las citas almacenadas en la base de datos y mostrarlas en el panel de administración.

Autenticación del administrador

Antes de enviar la solicitud, el componente recupera el token de autenticación desde localStorage mediante localStorage.getItem("token").

El token se envía posteriormente al backend en la cabecera Authorization utilizando el formato Bearer token. Esto permite que el backend verifique la identidad del usuario antes de devolver los datos.

Procesamiento de la respuesta de la API

Después de recibir la respuesta, el componente comprueba varias posibles estructuras de datos. Puede recuperar directamente un array desde response.data, desde response.data.data o desde response.data.appointments.

Esta verificación permite que el componente siga siendo compatible con diferentes estructuras de respuesta del backend.

Gestión de errores

Los errores se capturan mediante un bloque try...catch. Cuando ocurre un error, se muestra en la consola mediante console.error() y la lista de citas se restablece a un array vacío.

Visualización del estado

La función getAppointmentStatusLabel() transforma los estados técnicos recibidos desde el backend en etiquetas más comprensibles para el administrador.

Por ejemplo, Pending se convierte en "Pendiente", Confirmed en "Confirmada", Rejected en "Rechazada" y Cancelled en "Cancelada".

Visualización de las citas

Las citas se recorren mediante el método .map(). Para cada cita, el componente crea una tarjeta que contiene la información del cliente.

La propiedad appointment._id se utiliza como clave única para permitir que React identifique cada elemento. La fecha se convierte mediante new Date() y luego se muestra en formato francés mediante toLocaleDateString("fr-FR").

💳 Panel de pagos

DashboardPayments.jsx es el componente React que permite a la administración consultar y gestionar los pagos registrados en el sistema.

Recupera los pagos desde el backend, muestra información relacionada con el cliente y la transacción y proporciona varias acciones para modificar o eliminar un pago.

Gestión del estado

El componente utiliza dos estados principales. La variable payments contiene la lista de pagos recuperados desde la API, mientras que loading indica si los pagos todavía se están recuperando.

Recuperación de pagos

El hook useEffect llama a la función fetchPayments() cuando se carga el componente. Esta función envía una solicitud HTTP GET a /api/payments.

Cuando se reciben los datos, se almacenan en el estado payments. React actualiza automáticamente la interfaz para mostrar los pagos.

Contador de pagos

El número de pagos se calcula mediante payments.length. De esta manera, el componente muestra dinámicamente el número total de pagos recibidos.

El texto también se adapta automáticamente entre "pago" y "pagos" según el número registrado.

Modificación del estado

La función updateStatus() permite al administrador modificar el estado de un pago. Envía una solicitud HTTP PUT a /api/payments/:id con el nuevo estado.

Esta funcionalidad permite confirmar un pago con el estado Paid o marcarlo como fallido con el estado Failed.

Eliminación de un pago

La función deletePayment() permite eliminar un pago. Antes de eliminarlo, window.confirm() muestra una solicitud de confirmación para evitar una eliminación accidental.

Si el administrador confirma la eliminación, se envía una solicitud HTTP DELETE a /api/payments/:id. Después de la eliminación, la lista de pagos se actualiza mediante fetchPayments().

Visualización de los estados

El componente utiliza varias condiciones para mostrar una etiqueta diferente según el estado almacenado en la base de datos. El estado Paid representa un pago confirmado, Pending un pago pendiente, Failed un pago fallido y Refunded un pago reembolsado.

Acciones administrativas

Los botones de acción se muestran dinámicamente. El botón "Confirmar pago" aparece cuando el pago todavía no está marcado como Paid. El botón "Rechazar" aparece cuando el pago todavía no está marcado como Failed.

El botón "Eliminar" permanece disponible para permitir al administrador eliminar el pago después de la confirmación.

🏠 Página de inicio

Home.jsx representa la página de inicio principal de la aplicación Solar Energy. Este componente se mantiene intencionadamente simple porque combina varios componentes React existentes para construir la interfaz de inicio.

Principalmente muestra el componente Auth así como el componente Testimonials.

Componente Auth

El componente Auth se integra directamente en la página mediante <Auth />. Permite gestionar la autenticación de los usuarios, incluyendo el inicio de sesión y el registro según la implementación del componente.
