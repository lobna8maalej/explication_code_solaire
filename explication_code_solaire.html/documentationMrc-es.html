📚 1. Presentación general

Esta parte del backend constituye una API REST desarrollada con Node.js, Express y MongoDB/Mongoose.

Permite gestionar varias funcionalidades de la plataforma Solar Energy:

  • 🔐 Autenticación con JWT
  • 📅 Gestión de citas
  • ☀️ Gestión de paneles solares
  • 🔋 Gestión de baterías
  • ⚡ Gestión de inversores
  • 📄 Gestión de solicitudes de presupuestos
  • 💳 Gestión de pagos
  • ⭐ Gestión de opiniones de clientes
  • 📩 Gestión de contactos
  • 📊 Gestión del dashboard
  • 📁 Gestión de archivos con Multer

🔐 2. Middleware verifyToken

El middleware verifyToken permite proteger determinadas rutas de la API mediante un token JWT.

Importación de jsonwebtoken

 
const jwt = require("jsonwebtoken");

La biblioteca jsonwebtoken permite crear y verificar tokens JWT.

Creación del middleware

 
const verifyToken = (req, res, next) => {

El middleware recibe tres parámetros:

  • req: la solicitud HTTP
  • res: la respuesta HTTP
  • next: permite continuar hacia la siguiente función

Obtención del header Authorization

 
console.log( 
    "Authorization :", 
    req.headers.authorization 
); 
 
const token = 
    req.headers.authorization?.split(" ")[1];

El frontend normalmente envía el token con el siguiente formato: 

 
Authorization: Bearer TOKEN

El método split(" ") separa: 

 
Bearer 
TOKEN

El segundo elemento, con el índice [1], corresponde al token.

Verificación de la existencia del token

 
if (!token) { 
 
    return res.status(401).json({ 
 
        success: false, 
 
        message: "Accès refusé, token manquant", 
 
    }); 
 
}

Si no se envía ningún token, el servidor devuelve un error 401 Unauthorized.
