Configuration des variables d'environnement

Le fichier .env contient les variables d'environnement nécessaires au fonctionnement du backend de la plateforme Solar Energy. Ces variables permettent de configurer le serveur, la base de données, l'authentification, les paiements, le stockage des images et l'envoi des emails.

Important : les clés API, secrets, mots de passe et identifiants ne doivent jamais être publiés dans la documentation, sur GitHub ou dans le code source accessible publiquement.

Exemple de fichier .env


PORT=3000

MONGO_URI=mongodb://127.0.0.1:27017/solar_db

JWT_SECRET=your_secret_key

STRIPE_SECRET_KEY=your_stripe_secret_key

CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret

EMAIL_USER=your_email@example.com
EMAIL_PASS=your_email_app_password

Explication des variables

PORT

PORT définit le port utilisé par le serveur Node.js/Express. Dans cet exemple, le backend fonctionne sur le port 3000.

MONGO_URI

MONGO_URI contient l'URL de connexion à MongoDB. La base de données utilisée par la plateforme est ici appelée solar_db.

JWT_SECRET

JWT_SECRET est une clé secrète utilisée pour générer et vérifier les JSON Web Tokens (JWT). Ces tokens permettent notamment de sécuriser l'authentification et l'accès aux fonctionnalités protégées.

STRIPE_SECRET_KEY

STRIPE_SECRET_KEY correspond à la clé secrète utilisée pour communiquer avec l'API Stripe depuis le backend. Elle permet notamment de créer et gérer les opérations de paiement.

La clé Stripe doit rester strictement confidentielle et ne doit jamais être placée dans le frontend ou publiée dans un dépôt GitHub. Lors du déploiement chez un client, cette variable doit être configurée avec la clé Stripe du propre compte du client.

CLOUDINARY_CLOUD_NAME

CLOUDINARY_CLOUD_NAME identifie le compte Cloudinary utilisé pour stocker et gérer les images de la plateforme.

CLOUDINARY_API_KEY

CLOUDINARY_API_KEY correspond à la clé API utilisée par le backend pour communiquer avec Cloudinary.

CLOUDINARY_API_SECRET

CLOUDINARY_API_SECRET est le secret associé au compte Cloudinary. Il doit rester confidentiel.

EMAIL_USER

EMAIL_USER contient l'adresse email utilisée par le backend pour envoyer des emails, par exemple les notifications ou les confirmations.

EMAIL_PASS

EMAIL_PASS correspond au mot de passe ou au mot de passe d'application utilisé pour l'authentification du service d'envoi d'emails. Il ne doit jamais être exposé publiquement.

Sécurité

Le fichier .env doit être ajouté au fichier .gitignore afin d'éviter son envoi accidentel vers GitHub. 


.env
node_modules/

Lorsqu'un projet est déployé, les variables d'environnement doivent être configurées directement dans l'environnement sécurisé du serveur ou de la plateforme d'hébergement.
