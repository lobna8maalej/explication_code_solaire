# 29 — Configuração principal do Backend com Express

O arquivo app.js constitui o ponto central de configuração do Backend Solar Energy.

Ele permite inicializar o Express, configurar o CORS, gerenciar as requisições JSON, registrar as diferentes rotas da API, gerenciar o webhook do Stripe e tratar os erros e as rotas inexistentes.

Importação do Express e do CORS 

const express = require("express");
const cors = require("cors");

const app = express();

express permite criar e configurar o servidor Backend.

cors permite autorizar as requisições provenientes do frontend React.

express() cria a aplicação Express que será posteriormente utilizada para registrar os middlewares e as rotas.

Configuração do CORS 

app.use(
    cors({
        origin: "http://localhost:5173",
        methods: [
            "GET",
            "POST",
            "PUT",
            "DELETE",
            "PATCH"
        ],
        credentials: true,
    })
);

O CORS permite que o Backend aceite as requisições enviadas pelo frontend React.

Neste projeto, o frontend funciona em:

Frontend:
http://localhost:5173

A propriedade origin autoriza especificamente esta origem.

A propriedade methods indica os métodos HTTP autorizados pelo servidor.

credentials: true permite o uso de informações de autenticação nas requisições quando necessário.

Gerenciamento do Webhook do Stripe 

app.post(
    "/api/payments/webhook",

    express.raw({
        type: "application/json",
    }),

    require("./controllers/paymentController").stripeWebhook
);

Esta rota recebe as notificações enviadas pelo Stripe relacionadas aos eventos de pagamento.

O webhook utiliza express.raw() para receber o corpo original da requisição na forma de dados brutos.

Importante:

O webhook do Stripe é colocado antes do express.json(). Essa organização é necessária porque o Stripe pode precisar do corpo bruto da requisição para verificar corretamente a assinatura do webhook.

Middleware JSON 

app.use(express.json());

Este middleware permite que o Express leia as requisições que contêm dados JSON.

Por exemplo, quando um formulário React envia: 

{
    "name": "Lobna",
    "email": "client@example.com",
    "phone": "58229886"
}

O Express transforma automaticamente os dados JSON para que eles possam ser acessados em: req.body.

Gerenciamento de dados URL-encoded 

app.use(
    express.urlencoded({
        extended: true,
    })
);

Este middleware permite que o servidor processe os dados enviados no formato application/x-www-form-urlencoded.

A opção extended: true também permite gerenciar estruturas de dados mais complexas.

Rota principal de teste 

app.get("/", (req, res) => {

    res.status(200).json({
        success: true,
        message: "☀️ Solar API is running...",
    });

});

Esta rota permite verificar rapidamente se a API Backend está funcionando corretamente.

Resultado:

Quando o usuário acessa a raiz do Backend, o servidor retorna uma resposta JSON indicando que a API Solar Energy está funcionando.

    # 31 — Configuração do arquivo .env





    O arquivo .env contém as variáveis
    de ambiente utilizadas pelo Backend Solar Energy.





    Ele permite centralizar a configuração do servidor
    e as informações sensíveis necessárias para os diferentes
    serviços utilizados pela aplicação: MongoDB, JWT,
    Stripe, Cloudinary e envio de e-mails.






```
⚠️ Atenção:





O arquivo .env pode conter informações
sensíveis. Ele nunca deve ser publicado no GitHub ou
integrado diretamente ao frontend React.
```
